# 嘉然 Diana × Codex｜日夜双主题开源皮肤

给日常使用的 Codex 做了一套嘉然 Diana 主题皮肤。

暗夜和日间版本都已经配好。界面保留 Codex 原本的工作区布局和交互，只调整配色、按钮状态与边角装饰；立绘、简笔画、阿草和嘉心糖元素尽量待在工作区边缘，不打断写代码和阅读内容。

主题文件、安装脚本、自动挂载工具、模拟演示页面和宣传视频工程都已经开放。后面也会继续跟进 Codex 的界面更新与兼容性调整。
