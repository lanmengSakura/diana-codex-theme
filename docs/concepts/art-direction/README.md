# Diana Codex art-direction studies

These three ImageGen studies are visual references, not final product screenshots.
Generated interface text and controls must not be copied directly into the implementation.

## A — Quiet Paper Theatre

- File: `diana-concept-a-paper-theatre.png`
- Goal: warm editorial paper, asymmetric workspace, and a large Diana figure occluded behind the active task sheet.
- Implementation takeaway: rebuild the depth relationship with real panels and responsive character cropping.

## B — Starberry Instrument Language

- File: `diana-concept-b-starberry-instrument.png`
- Goal: remove the large character and let stars, strawberry-seed dots, and bow-like double rules become a functional interface system.
- Implementation takeaway: start with selected states, progress, Diff markers, status rails, and composer endpoints.

## C — Quiet Scene Change

- File: `diana-concept-c-quiet-scene.png`
- Goal: preserve a calm central workspace while limiting the character, line art, one light sweep, and one glint to a right-side stage zone.
- Implementation takeaway: build a still resting state plus a single non-looping transition with a reduced-motion fallback.

## Shared prompt constraints

- Use case: `ui-mockup`
- Landscape art-direction image for a Codex desktop workspace.
- Diana source art is the authoritative identity and outfit reference.
- Approved line-art masks are motif references.
- No readable long-form text, logo, watermark, browser chrome, device frame, neon gradient, or generic floating-card dashboard.
- The central task content remains visually dominant.
