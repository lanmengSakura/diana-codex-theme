# Diana Codex Theme v0.2.5

## 超长会话刻度修复

`v0.2.5` 修复了 Starberry 消息导航轨在超长会话中过度密集的问题。当 Codex 需要在窄轨道中显示大量用户消息落点时，旧样式会让普通莓粉刻度连成明显的“梯子”。

新版按消息数量自动切换密度：

- 40 条以内：保持原有视觉节奏。
- 41–80 条：缩短、变细并淡化普通刻度。
- 81 条以上：进入紧凑档，以五格和十格节点维持可扫视性。

密度规则只作用于非当前刻度。真实落点的八角星、强刻度、悬停与键盘焦点反馈、Codex 原生点击区域都没有改变。

## 同步范围
