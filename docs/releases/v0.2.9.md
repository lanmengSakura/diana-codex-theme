# Diana Codex Theme v0.2.9

> 2026-08-24 · Codex 顶部层级、右侧面板标题与安装接续兼容更新

`v0.2.9` 将 `v0.2.8` 发布后已经在真实 Codex `26.818.5229.0` 上确认的兼容经验收入正式 Skill 包。本次不改变定稿美术方向，也不在公开包中加入桌面运行器。

## 本次修复

### 顶部渐变与装饰层级

- 保留 Codex 原生固定工具栏与主工作区顶部渐变，不删除渐变。
- 实测渐变为 `62px`（`46px` 实色加 `16px` 过渡），但该数值只用于当前构建诊断，不作为跨版本常量。
- 适配器必须找到同时包含真实会话视口与输入框的直属前景层，只标记这一层。
- 禁止对主工作区所有直属子层批量设置 `position` 或 `z-index`；该写法会把原生固定工具栏改成普通流布局，使渐变下移并遮住顶部装饰。
- 上方线稿保持不可交互并位于任务内容下方。只有实测仍偏暗时，才允许单独对右上细线做克制的透明度补偿。

### 右侧面板标题星星

- 不再匹配“环境信息”“Environment”或“输出内容”等固定标题。
- 先定位可见的右侧原生面板，再识别第一条包含有效文字的标题行。
- 星星使用独立的 `aria-hidden` 节点挂在标题行起始处，不修改 Codex 原生文字。
- 面板重绘、内容切换或折叠后清理旧节点并恢复当前节点，始终只保留一个。
- 日间与暗夜继续使用 `21 × 21px`、`.64 / .72` 透明度和 `pointer-events: none`。

### 安装流程接续

- Skill 安装完成后，用户在下一条消息回复“继续”，Codex 应恢复原先的完整主题挂载请求。
- 不重复安装 Skill，不让用户再次粘贴命令。
- 重启 Codex、开启 CDP 或建立自动挂载仍然必须分别说明计划并等待确认。

## 安全边界

- 公开 Skill ZIP 不包含 CDP 运行器、监听端口、后台 watcher、计划任务或登录启动项。
- 公开仓库不包含本机实验适配器；需要完整角落美术且没有正式入口时，由用户自己的 Codex 在用户可写目录中现场生成。
- 本机实验必须先核对当前 Codex 版本、进程和恢复方法，并在用户明确确认后才允许建立临时调试连接。
- 日间、暗夜 CSS 蓝图与美术资源全部保留，终端主题与本次桌面兼容修复相互独立。
