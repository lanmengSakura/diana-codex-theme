# Diana Codex Theme v0.2.3

## 完整视觉入口

普通安装指令现在默认以完整 Diana 视觉为目标，包括日夜配色、角落立绘、阿草、星星、糖果和叙事线稿。Skill 会先检查当前 Codex 版本是否提供正式主题、插件、Pet、扩展或用户样式入口。

如果没有正式入口，用户自己的 Codex 可以提出针对当前机器的实验适配方案。它必须在打开 CDP 前告知同机访问风险，列出进程、端口、文件、日志、资源占用、启动方式和完整卸载方法，并等待用户确认。

## 发行边界

- 仓库和发行包不包含 CDP 启动器、监听器、watcher 或计划任务。
- 本机实验适配器不会写入 Codex 安装包，也不会进入 Diana 仓库或 Release。
- 首次部署只允许手动、临时运行，并必须验证停用、完整退出、正常重开和恢复。
- 启动后自动挂载属于第二次独立授权。
