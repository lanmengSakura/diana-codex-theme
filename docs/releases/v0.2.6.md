# Diana Codex Theme v0.2.6

## 嵌套消息轨兼容修复

`v0.2.6` 修复了 `v0.2.5` 长会话密度规则没有命中当前 Codex 桌面端真实结构的问题。

`v0.2.5` 已加入 41 条和 81 条两档自适应密度，但当时按“消息按钮是导航栏直接子级”编写选择器。当前 Codex 会在导航栏和按钮列表之间加入滚动容器，因此规则虽然成功载入，视觉上仍会保持原来的粉色密集刻度。

新版改为识别导航栏内部的嵌套消息按钮，同时继续保留：

- Codex 原生点击跳转区域。
- 唯一的真实当前落点八角星。
- 当前落点强刻度。
- 悬停和键盘焦点反馈。

## 真实界面验证

在当前 Codex `26.818.5229.0`、包含 208 条用户消息的真实任务中回读计算样式：

- 普通非当前刻度：1px 高、20% 长度、24% 不透明度。
- 每十条的弱节点：2px 高、52% 长度、50% 不透明度。
- 当前落点：3px 高、76% 长度、72% 不透明度，并保留八角星。
- 当前落点数量：1。

日间、暗夜源主题与独立 Skill 内置蓝图已同步。
