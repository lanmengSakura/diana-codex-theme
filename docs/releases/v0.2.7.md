# Diana Codex Theme v0.2.7

## 恢复发布预览的消息轨比例

`v0.2.7` 修正了 `v0.2.6` 在超长会话中把大多数刻度压得过窄的问题。

上一版已经能够识别当前 Codex 的嵌套消息轨，但主要通过横向缩短线段来降低密度。这样虽然消除了连续的粉色梯子，却偏离了发布预览中“短线、常规线和当前星标”组成的宽窄节奏。

新版改为保留参考页的线段比例，通过减少可见刻度数量控制长会话密度：

- 40 条以内保持原有节奏。
- 41–80 条保持参考比例，只适度降低明暗。
- 81 条以上每三条显示一条约 11px 常规线。
- 每十条保留一个约 18.7px 长节点。
- 当前落点约 19.8px，并保留唯一八角星。
- 暂不显示的刻度只隐藏视觉线段，36×10px 原生按钮和点击跳转能力不变。

## 真实界面验证

在当前 Codex `26.818.5229.0`、包含 210 条用户消息的真实任务中完成计算样式回读和整屏截图核对：

- 隐藏刻度：10.92px 几何宽度、2px 高、透明度 0。
- 常规可见刻度：10.92px 宽、2px 高、38% 不透明度。
- 十格长节点：18.72px 宽、2px 高、60% 不透明度。
- 当前落点：19.76px 宽、3px 高、72% 不透明度，当前数量为 1。

日间、暗夜源主题与独立 Skill 内置蓝图已同步。
