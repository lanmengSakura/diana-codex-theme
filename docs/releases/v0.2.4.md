# Diana Codex Theme v0.2.4

## 安装流程修复

`v0.2.4` 修复了 `v0.2.3` 中“把 ZIP 拖进 Codex，然后在同一条消息安装并挂载”的不稳定流程。

推荐安装方式改为：

1. 让 Codex 使用 `$skill-installer` 从仓库的 `skills/diana-codex-theme` 路径安装。
2. 安装完成后，在下一条消息调用 `$diana-codex-theme` 完整挂载主题。

Release ZIP 继续提供，但定位调整为离线保存和手动安装备用。附件被上传或解压不代表 Skill 已经注册。

## 更清楚的完成状态

- `skill_available`：Skill 已加载，尚不代表界面变化。
- `native_palette_applied`：真实 Codex 配色已部署并验证恢复。
- `full_artwork_mounted`：真实工作区可见立绘和装饰，交互与恢复验证通过。
- `deployment_blocked`：Skill 可用，但正式入口、授权或运行验证不足。

完整视觉仍是默认目标。若只能使用实验性 CDP，Codex 必须先通知同机访问风险并等待确认；自动挂载需要第二次独立确认。

## 发行边界

- 仓库和附件不包含 CDP 启动器、监听器、watcher 或计划任务。
- 不修改 `WindowsApps`、MSIX、`app.asar`、应用签名或 macOS `.app`。
- Windows Terminal 包继续使用本地静态 PNG 与原生 Fragment，不依赖后台进程。
