# Diana Codex Theme 0.2.2

这是一次安全边界修复版本。

## 主要变化

- 公开项目不再启动或连接 Codex 的 CDP 调试端口。
- 移除桌面 watcher、自动挂载和 `.codedrobe-theme` 附件。
- 保留 Diana Night / Day 原生配色、完整美术资产、CSS 蓝图与在线演示。
- Diana Skill 改为安全决策流程：先用官方外观；只有正式支持的用户空间入口才能部署完整立绘。
- Windows Terminal 主题保持正式支持，不受桌面运行时变更影响。
- 提供 `security:remove-legacy` 与 `security:audit` 帮助旧用户完成迁移。

## 发行附件

- `diana-terminal-0.2.2.zip`：Windows Terminal 静态主题与可恢复安装工具。
- `diana-codex-theme-skill-0.2.2.zip`：日夜配色、完整美术、CSS 蓝图与安全部署规则。

本版本不提供任何可执行的 Codex 桌面注入包。
