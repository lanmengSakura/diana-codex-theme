# Diana Codex Theme 0.2.1

> [!CAUTION]
> 桌面注入附件已因本机无认证 CDP 安全边界问题停止分发。请升级到 `v0.2.2`，执行 `npm run security:remove-legacy`，完全退出并正常重开 Codex。Windows Terminal 附件不受影响。

这个补丁版本解决了一个容易混淆的问题：Windows 可以把 CMD 或 PowerShell 交给 Windows Terminal 打开，但外部脚本不一定会自动选中 Diana 配置。现在可以为常用脚本生成专用 Diana 入口。

## 本次更新

- 新增 `new-diana-terminal-shortcut.ps1`，支持 `.cmd`、`.bat` 与 `.ps1`。
- 按文件类型明确选用 `Diana CMD` 或 `Diana PowerShell`，完整保留终端背景与配色。
- 默认在开始菜单的 `Diana Terminal` 文件夹创建入口，也可以把快捷方式放在原脚本旁边。
- 不修改原脚本、注册表和系统终端代理，不新增常驻进程。
- 打包脚本统一从项目版本读取附件版本号。

Diana Night、Diana Day 与终端美术资源未改版，本次只补齐脚本启动路径和文档。

## 发行附件

- `diana-terminal-0.2.1.zip`：Windows Terminal 主题、双路线安装入口、脚本快捷方式工具和卸载工具。
- `diana-night-0.2.1.codedrobe-theme`：Diana Night 桌面主题。
- `diana-day-0.2.1.codedrobe-theme`：Diana Day 桌面主题。
- `diana-codex-theme-skill-0.2.1.zip`：自包含主题 Skill，含定稿日夜蓝图与美术素材。

Windows Terminal 主题要求 `1.24` 或更高版本；当前实机验证版本为 `1.24.11911.0`。Codex 桌面主题当前验证基线仍为 Windows 11 / Codex `26.814.5517.0`。
