# Diana Codex Theme 0.2.0

本次版本将 Diana Terminal 暗夜主题并入公开项目，同时保留原有 Diana Night、Diana Day 与自包含 Skill。

## Diana Terminal

- 新增 `Diana PowerShell` 与 `Diana CMD` 两个 Windows Terminal 配置。
- 左侧信息密集区保持透明；右上复用桌面暗夜版星星、弧线与草莓线稿，右下缩入嘉然立绘、两颗手绘星、糖果、棒棒糖和两只阿草。
- 使用 Windows Terminal 当前用户 Fragment 与本地静态 PNG，不启用 Acrylic、动画、像素着色器或后台进程。
- 提供两种安装路线：独立保留，或备份后将 Diana PowerShell 设为当前用户默认配置。
- 安装时创建 `Diana PowerShell`、`Diana CMD` 开始菜单快捷方式；卸载时一并移除，并在安全条件满足时恢复原默认项。

## 发行附件

- `diana-terminal-0.2.0.zip`：终端主题、双路线安装入口和卸载工具。
- `diana-night-0.2.0.codedrobe-theme`：Diana Night 桌面主题。
- `diana-day-0.2.0.codedrobe-theme`：Diana Day 桌面主题。
- `diana-codex-theme-skill-0.2.0.zip`：自包含主题 Skill，含定稿日夜蓝图与美术素材。

Windows Terminal 主题要求 `1.24` 或更高版本；当前实机验证版本为 `1.24.11911.0`。Codex 桌面主题当前验证基线仍为 Windows 11 / Codex `26.814.5517.0`。
