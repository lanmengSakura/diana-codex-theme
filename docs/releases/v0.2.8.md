# Diana Codex Theme v0.2.5–v0.2.8

## 同一批消息导轨修复

`v0.2.5` 到 `v0.2.8` 属于同一轮 Starberry 消息导轨修正。前三个版本分别解决超长会话过密、当前 Codex 嵌套结构兼容和参考页比例恢复；`v0.2.8` 将实际界面反馈汇总为最终混合方案。

### 这轮迭代解决了什么

- `v0.2.5`：为长会话加入消息数量分档，处理密集刻度连成“粉色梯子”的问题。
- `v0.2.6`：让规则命中当前 Codex 在滚动容器内嵌套消息按钮和 MarkerLine 的结构。
- `v0.2.7`：恢复参考页的短线与分隔线比例，但间隔隐藏仍会让导轨显得断续，规则节奏也偏整齐。
- `v0.2.8`：所有普通刻度恢复为可见的 2px 实线，以不规则短线和每五条一次的变化分隔构成稳定节奏，并保留 Codex 原生悬停起伏。

## v0.2.8 最终方案

导轨按真实用户消息总量切换三档：

| 档位 | 消息数 | 视觉策略 |
|---|---:|---|
| 疏 | `1–32` | 起伏较开，五格分隔更明显 |
| 中 | `33–96` | 收紧普通短线，保留完整分隔节奏 |
| 密 | `97+` | 普通线更短，但不再隐藏任何真实消息刻度 |

每一档都遵守以下约束：

- 每条真实消息仍对应 Codex 原生按钮和完整点击区域。
- 普通线为 2px 实色，不再出现灰粉叠层、虚线或透明空格。
- 每五条出现一次分隔，但分隔自身也有多种长度，不形成刻度尺。
- Codex 原生 `--marker-progress` 继续负责悬停附近的动态起伏，鼠标移开后回到静态不规则节奏。
- 当前视口只保留一个八角星与强刻度。
- 导轨首尾菱形始终可见；当前消息位于第一条或最后一条时也不会吞掉端点。

## 日间颜色锁定

Diana Day 没有直接移植暗夜实色。日间版继续使用 `v0.2.4` 及更早版本的莓粉基准：

- 普通／分隔色相：`rgb(184 73 112 / 55%)`
- 当前刻度：`rgb(174 55 96 / 92%)`
- 普通、分隔、当前的视觉不透明度继续使用 `0.72 / 0.9 / 0.78`

新版只更改层级、长度与节奏。嵌套 Marker 的外层保持透明，颜色只画在内层线段上，因此不会因两层叠加产生脏灰边。

## Skill 与安全边界

- 日间、暗夜源主题和独立 `diana-codex-theme` Skill 内置蓝图同步。
- Skill 新增精细导轨参考：本机适配器可按 `sparse / balanced / dense` 数组写入 `--diana-art-scale`，并复用已有 DOM 观察逻辑。
- CSS 自身提供无脚本回退，不需要为了消息导轨新增轮询、后台进程或监听端口。
- 公开包依旧不包含 CDP 运行器、watcher、自动注入或持久化任务。

Windows Terminal 美术和安装逻辑没有变化，仅随统一 Release 版本号重新打包。
