# Diana Codex Theme v0.2.10

> 2026-10-03 · Codex 桌宠/紧凑窗口透明保护

`v0.2.10` 是面向已发布 `v0.2.9` 的兼容性修复，不改变完整工作区的定稿美术方向。

## 本次修复

- 日间与暗夜主题在 `.compact-window`、`.diana-auxiliary-window` 下保持 `html`、`body`、`#root` 与主题表面透明。
- Codex 桌宠等原生透明辅助窗口不再被主题背景铺成整块矩形。
- 完整会话窗口继续使用原有 Diana 背景、装饰线、立绘与交互层级。
- 根主题、独立 Skill 与启动器运行时副本同步更新，并通过透明窗口回归测试、主题校验与 Skill 清单校验。
